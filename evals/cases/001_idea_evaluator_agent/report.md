# 想法评估报告：投资人视角的想法决策 Agent

报告状态：Phase 0 内部方法样例  
评估日期：2026-07-28  
评估模式：部分深度研究  
项目阶段：S0 想法阶段  
结论置信度：中

> 本报告是决策支持材料，不是商业成功预测、投资建议、法律意见或税务意见。当前只有提出者本人的需求描述，尚未完成目标用户、竞品、市场规模和付费意愿研究。

## 首屏结论

**结论：先验证。**

这个方向值得继续，但现在最值得验证的不是“能不能做出一个覆盖全行业的 AI 投资人”，而是：

> 独立工作者是否愿意让一个有证据、有记忆、会复评的系统，持续参与自己真实的时间和资金分配决策。

最有价值的一点：把一次性 AI 建议升级为长期的个人决策记录，结合想法历史、身份资源、证据和复评。

最大风险：如果用户只想免费生成一次“看起来专业”的报告，它会迅速变成低频、易替代的内容生成器。

现在最该做的一件事：先为 5 名真实目标用户手工完成高质量报告，观察他们是否采取行动，并在获得新证据后主动回来复评。

## 四类价值判断

| 类型 | 当前判断 | 说明 |
|---|---:|---|
| 用户价值 | 3/5 | 提出者痛点清晰，但尚无独立用户证据 |
| 商业价值 | 2/5 | 可能收费，但购买者、频率、价格和成本未知 |
| VC 适配度 | 2/5 | 当前没有增长、市场、防御性或单位经济性证据 |
| 提出者适配度 | 暂不评分 | 缺少技能、时间、预算、渠道和目标资料 |

一个重要区分：即使它最后不适合风险投资，也可能成为有忠实用户的开源工具或可持续小生意。不能用“是否 VC 规模”决定它有没有价值。

## 想法重述

为独立开发者、创作者、自由职业者和早期创业者提供一个证据校准的决策 Agent：

1. 用户用自然语言输入一个想法；
2. Agent 重述想法并识别当前阶段；
3. 只提出最可能改变结论的少量问题；
4. 从用户价值、商业、市场、竞争、分发、可行性、个人匹配和资本等方面评估；
5. 区分事实、用户陈述、推断、假设和未知；
6. 给出推进、先验证、重构、暂存或停止的阶段性结论；
7. 把结论转化为带输入、产出和停止条件的现实实验；
8. 新证据出现后复评；
9. 多个想法累积后，再分析用户的专长、盲点和长期方向。

## 为什么可能成立

### 1. 底层问题不是“缺少想法”，而是缺少决策

提出者真正需要的是外部判断、反方挑战、现实验证和长期反思，而不只是更多灵感。这意味着产品可以围绕“做不做、先验证什么、何时停止”创造价值。

### 2. 长期连续性可能比一次报告更有差异

通用模型可以写商业分析，但通常不会天然拥有：

- 一个想法的版本历史；
- 用户的时间、预算、技能和渠道；
- 过去实验产生的证据；
- 之前预测与现实结果的偏差；
- 多个想法之间的资源复用和盲点；
- 明确的复评条件。

这些内容若被用户持续使用，可能构成真正的产品层。

### 3. 原型技术可行

[OpenAI Agents SDK](https://github.com/openai/openai-agents-python) 已提供工具、guardrail、session 和 tracing 等构建模块；[LangGraph](https://github.com/langchain-ai/langgraph) 提供有状态、持久执行和人工介入能力。它们证明基础工程不需要从零发明，但不证明本产品的判断质量已经解决。

### 4. 可以非常低成本地先验证

[YC 的早期创业建议](https://www.ycombinator.com/blog/ycs-essential-startup-advice/)强调尽快接触用户和用低成本方式学习。这个产品尤其适合先做人工 concierge：在自动化之前，先证明什么报告内容真的改变行为。

## 为什么可能不成立

### 1. 一次性报告非常容易商品化

如果产品价值只是“根据想法写一份完整投资报告”，通用聊天模型、模板、商业计划工具和真人顾问都能替代。

### 2. 需求可能是提出者个人的强需求，不是普遍需求

当前没有证据说明其他用户：

- 多久做一次想法判断；
- 会为错误判断付出什么代价；
- 对现有工具哪里不满意；
- 是否愿意提交敏感的真实想法；
- 是否会重复使用；
- 是否愿意付费。

### 3. 长报告可能制造虚假权威

报告越完整，越容易让用户误以为结论“经过科学证明”。这类产品对用户的时间和资金决策有影响，因此需要分层 guardrail、人工介入、持续评测和明确限制。[OpenAI 的 Agent 指南](https://openai.com/business/guides-and-resources/a-practical-guide-to-building-ai-agents/)与 [NIST AI RMF](https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-ai-rmf-10)都强调持续风险管理和评测。

### 4. 高质量研究可能不符合订阅经济性

真正有价值的报告需要搜索、来源验证、结构化推理、可能的专家复核和长期存储。若用户一年只使用几次，深度报告成本可能高于可接受订阅价格。

| 维度 | 分数 | 核心判断 |
|---|---:|---|
| 问题强度 | 2/5 | 本人痛点真实，外部需求未知 |

| 方案价值与行为变化 | 3/5 | 可能帮助行动，尚未证明改变行为 |
| 时机 | 3/5 | 工具成熟也意味着竞争门槛降低 |
| 市场与扩张 | 2/5 | 扩张叙事存在，可触达市场未知 |
| 竞争与差异化 | 2/5 | 一次报告弱，长期复评尚待验证 |
| 商业模式与经济性 | 2/5 | 开源加托管是未验证假设 |
| 分发与销售 | 2/5 | GitHub 可获反馈，非技术用户渠道未知 |

| 提出者适配度 | 未评分 | 身份资料不足 |

| 资本与回报形态 | 3/5 | 早期资本高效，暂不适合融资 |

## 目前最强的产品版本

建议将第一版定位从：

> 覆盖所有行业的 AI 投资人。

收窄为：

> 面向独立工作者的想法复评系统：帮助用户用证据决定下一步，并根据现实结果持续修正判断。

第一版只需要做好：

- 一个自然语言想法；
- 一次重述；
- 最多三个关键问题；
- 事实、推断、假设和未知；
- 五档阶段性结论；
- 7 天和 30 天实验；
- 新证据后的复评。

身份模板、多想法洞察、行业包和融资模块都保留在架构中，但不同时自动化。

## 最关键的未知项

1. 用户是否真实、反复地经历这一问题？
2. 什么输出会改变行为：结论、证据、行动计划、复评还是个人洞察？
3. 用户会不会在获得新证据后主动回来？
4. 提出者能通过什么渠道直接找到首批用户？
5. 用户愿意为什么收费单位付款？

其中前三项会直接改变“先验证”这个结论。

## 7 天计划

目标：验证问题，不验证代码。

投入假设：

- 8–12 小时；
- 0–500 元；
- 10 名最近真正启动、放弃或纠结过项目的人。

动作：

1. 让对方展示最近一次真实决策，而不是讨论抽象偏好；
2. 记录触发、替代方式、时间/金钱代价和最终结果；
3. 找出最强的一个用户细分；
4. 邀请至少 3 人提供真实想法参加人工报告。

成功信号：

- 至少 6 人过去半年经历两次以上类似决策；
- 至少 5 人已有记录、咨询、搜索或模型流程；
- 至少 3 人愿意提交真实想法。

若大多数人只是觉得概念有趣，却没有真实行为，应重构问题。

## 30 天计划

目标：验证报告是否改变行为。

投入假设：

- 25–45 小时；
- 0–2,000 元；
- 5 名同一细分用户；
- 1–2 名创业或投资经验评审者。

动作：

1. 使用固定 Schema 手工完成 5 份报告；
2. 一周后检查用户真正执行了什么；
3. 30 天后用新证据复评；
4. 记录用户纠正、专家分歧和报告变化；
5. 做真实价格选择或小额预付测试。

成功信号：

- 至少 3 人执行建议实验；
- 至少 3 人回来复评；
- 至少 2 人愿意进行真实付费测试；
- 专家没有发现明显致命遗漏或伪造事实。

在这个门通过之前，不应自动化完整 Agent。

## 90 天计划

只有 30 天门通过后才进入。

目标：

- 验证自然复评；
- 验证多个想法使用；
- 测量单份报告成本；
- 找到真实收费单位；
- 确定开源核心和托管能力的边界。

此阶段预计投入为 60–120 小时和 1,000–10,000 元。该范围只是情景假设，不是项目报价或财务预测。

## 融资判断

当前融资准备度：**不具备融资条件**。  
建议路径：**自筹验证**。

原因：

- 市场未验证；
- 没有重复使用；
- 没有付费；
- 没有单位经济性；
- 没有分发优势；
- 没有证明长期数据或工作流优势。

下一个可能支持融资对话的里程碑：

> 在一个窄用户群中证明稳定复评、多个想法使用、真实付款和可控单次成本，并能解释为什么通用模型无法替代。

投资人最可能追问：

- 用户为什么不用通用模型？
- 这个问题多久发生一次？
- 用户会不会回来更新同一个想法？
- 谁持续付钱？
- 开源如何带来分发？
- 什么会形成长期优势？
- 如何证明判断质量，而不是只证明报告写得专业？

融资工具和公开募资规则取决于地区。美国 SEC 明确说明，私营公司的证券发行也受监管；正式操作应参考[监管机构资料](https://www.sec.gov/resources-small-businesses/capital-raising-building-blocks/private-companies-sec)并由相应地区的律师和财务专业人士复核。

## 最终判断

这个想法目前不是“无价值”，也不是“应该立刻全力开发”。

它真正值得验证的核心是：

> 人们是否愿意长期使用一个会记住想法、要求证据、暴露不确定性，并在现实结果出现后修改判断的系统。

如果这个行为成立，它可以从个人工具逐步扩展为创始人和创新团队的决策基础设施；如果不成立，就应及时收缩为更窄的研究、教练或开源个人工具。

下一次复评条件：完成 10 次问题访谈和 5 份人工报告，并获得真实行动、复评和付费信号。
