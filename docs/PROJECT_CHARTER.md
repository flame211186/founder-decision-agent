# 项目宪章

版本：0.2  
状态：核心方向已由用户确认  
最后更新：2026-07-28

## 1. 产品使命

帮助独立工作者、个人开发者和早期创业者，把模糊的自然语言想法转化为更高质量的现实决策。

产品采用早期投资人和创业操盘者的视角，但不扮演“能预言未来的投资人”。它应当：

- 识别一个想法真正解决的问题与潜在价值；
- 暴露关键漏洞、隐含假设、执行障碍和认知盲区；
- 判断当前最合理的动作是推进、验证、重构、暂存还是停止；
- 给出能以低成本获得高信息量的现实验证计划；
- 结合提出者的能力、资源、时间、资金、网络和风险承受能力进行个性化判断；
- 在多个想法累积后，帮助用户认识自己的优势、偏好、反复出现的盲点和更值得长期投入的方向。

## 2. 核心产品立场

### 2.1 它是决策支持系统，不是预测机器

创业成功存在路径依赖、运气、宏观变化和执行差异。产品不能承诺“判断正确”，只能通过更好的证据、校准、反方分析、透明假设和持续评测，提高判断质量。

### 2.2 它优先帮助创始人，而不是模仿投资人口吻

投资人是否愿意投资只是一个视角。一个好生意未必适合风险投资，一个值得个人完成的项目也未必需要巨大市场。报告必须分别评价：

- 用户价值；
- 生意价值；
- 风险投资适配度；
- 与当前提出者的匹配度。

四者不得混成一个总分。

### 2.3 阶段正确比绝对结论重要

只有想法时，最重要的是找出应验证的假设；已有用户时，最重要的是行为、留存和付费证据。系统必须先识别阶段，再使用对应标准，不能因为早期项目“没有收入”就机械判低分。

### 2.4 证据比自信措辞重要

所有重要结论都应能追溯到用户提供的信息、外部来源、确定性计算或明确假设。信息不足时，系统应主动降低置信度并提出高信息量问题。

## 3. 初始用户

首要用户：

- 独立开发者、设计师、创作者和自由职业者；
- 正在探索副业、产品或小型生意的人；
- 处于 idea、pre-seed 或早期验证阶段的个人或小团队；
- 同时积累多个想法、难以选择优先级的人。

后续扩展：

- 更成熟的创业团队；
- 不同行业从业者；
- 孵化器、创业教练和投资团队；
- 通过行业模板适配 SaaS、消费、市场平台、服务、内容、硬件、深科技和强监管业务。

扩展方式应是“身份模板 + 行业评估包 + 阶段模板”，而不是复制多套互不兼容的 Agent。

## 4. 核心用户结果

一次完整使用后，用户至少应知道：

1. 这个想法目前最合理的结论是什么，置信度为何；
2. 真正有价值的部分和最致命的问题分别是什么；
3. 哪些内容是事实，哪些仍是未经验证的假设；
4. 如果继续，未来 7 天和 30 天应该做什么；
5. 需要投入多少时间、资金、技能和外部资源；
6. 每一步预期获得什么证据或产出；
7. 达到什么条件才值得继续投入或开始融资；
8. 哪些修改、切入点或相邻方向可能更好；
9. 该想法是否适合当前这个人，而不仅是理论上是否成立。

多个想法累积后，用户还应知道：

1. 反复关注的用户、问题、行业和商业模式；
2. 稳定体现出的专长、独特洞察和资源优势；
3. 反复忽视的分发、验证、经济性、范围或执行问题；
4. 想法之间能否组合成一个更强的长期方向；
5. 未来值得主动寻找什么类型的问题和证据。

## 5. 不可牺牲原则

- 质量优先于发布速度。
- 真实不确定性优先于虚假确定性。
- 可操作建议优先于长篇泛泛而谈。
- 用户利益优先于迎合、夸奖或刻意打击。
- 证据与来源优先于模型常识。
- 隐私和可删除性优先于无边界记忆。
- 可解释、可评测的流程优先于不可控的全自主循环。
- 开源核心优先于仅能在单一产品中使用的实现。

## 6. 明确非目标

第一版不做：

- 保证创业成功、融资成功或投资回报；
- 证券买卖、资产配置或个股投资建议；
- 自动替用户联系投资人、群发融资材料或进行公开募资；
- 自动生成或签署法律、税务、证券发行文件；
- 把单一综合分数包装成客观真相；
- 在缺少证据时伪造 TAM、客户需求、竞品数据或财务预测；
- 一开始就覆盖所有行业和所有创业阶段；
- 以复杂多 Agent 架构本身作为产品卖点。

## 7. 成功定义

产品成功不是“报告很长”，而是同时满足：

- 用户能更快看见最关键的不确定性；
- 建议能转化为现实验证动作；
- 事实性主张有可检查来源；
- 相同信息下的关键结论具有合理稳定性；
- 当关键事实改变时，结论能敏感地随之改变；
- 专家或有经验的创业者认为分析没有遗漏明显致命问题；
- 用户能够理解为什么得到该结论，并能反驳、修正和迭代；
- 开源用户可以在不阅读内部代码的情况下安装、运行、配置和扩展。

具体指标和阈值在 Phase 0 的评测设计中确定，不在尚无基线时虚构数字。
